# support

afterflow is a personal cheat mod. if something breaks report it to @prsevend on discord with:

- your geode version
- your geometry dash version
- the stage you were on
- the relevant lines from the geode console and

the mod predicts where a click or release would take you by simulating a hidden ghost player then delays the input if pressing now would die and a later tick survives. it does not edit level data or collision or progression. it can still change the outcome of a run so treat every run with it as non legitimate
